Для каждой метрики агрегат показывает число пригодных пар `n`, медиану и диапазон внутри одного задания и профиля. Разность считается как обычный режим минус выбранный. Для Codex суммируются входные и выходные токены, кэшированные входные входят в input. Для Pi используется сумма `usage.totalTokens` по ходам сессии с полными данными. Ноль сохраняет значение измеренного нуля, `null` обозначает недоступную величину. Оценка AI Tester, стоимость из сессии Pi и фактическое списание имеют отдельные поля.

В `readClasses` учтены первое, повторное, изменённое, защищённое чтение и чтение новой сессии. Каждая строка наблюдений хранит число чтений и байты обычной и выданной нагрузки в этом порядке. В агрегате есть именованные суммы и разность. `readResultTextBytes` отдельно считает байты текста результатов инструментов по трассе, включая видимые служебные строки. У полных задач могут различаться число и выбор чтений. Эти байты характеризуют весь запуск. Хеши manifest, исходных копий и реализаций приведены в `pins`.

Исходный Windows-профиль Codex `gpt-5.6-luna` выполнил 2 из 45 запусков, оба завершились без ожидаемого ответа. Контрольные Windows-профили Codex `gpt-6-luna` и `gpt-6.1-terra` с ограниченным доступом выполнили соответственно 2/45 и 1/45 с таким же исходом. Нативный Codex через API получил отказ при первой попытке из 45. Закреплённый профиль Ornith в Pi был недоступен на Windows и Linux (0/27 на каждой ОС), нативный Codex в Linux был недоступен (0/45). Все запланированные ключи и причины сохранены отдельно по профилю и ОС.

### Воспроизведение

Из корня репозитория запустите команду, указав новый выходной файл в существующем каталоге. Для пересчёта достаточно Node.js 22+ и обезличенных строк. Имена проектов в снимке заменены на A и B.

```sh
node docs/memory-tools-research/context-dedup-ai-tester/issue-186/rebuild-snapshot.mjs docs/memory-tools-research/context-dedup-ai-tester/issue-186/snapshots/2026-11-25-windows-sqz-1.3.0/observations.json aggregate-rebuilt.json
```

Сравните полученный файл побайтово с `aggregate.json` из снимка. При существующем выходном файле сборщик завершится с ошибкой. Результаты проверок по ОС приведены ниже.

Для новых измерений используйте [манифест v3](matrix-manifest-v3.json). В нём закреплены версии генератора AI Tester и сборщика метрик Pi. Имя сценария AI Tester учитывает снимок и платформу. Для исторических трасс с прежними именами укажите соответствие файла и попытки в `manifest.attempts`. Pi сохраняет `usage.totalTokens`, когда провайдер сообщил полный счётчик. Опубликованные измерения относятся к [манифесту v1](matrix-manifest.json).

На Windows укажите путь к закреплённому `sqz.exe` в `AIFHUB_TEST_SQZ_WINDOWS_EXE`. Из корня репозитория выполните команды PowerShell с двумя новыми выходными каталогами. AI Tester подготовит 45 сценариев, Pi перечислит 27 ячеек в режиме `--dry-run`. Для этих команд доступ к модели не требуется.
