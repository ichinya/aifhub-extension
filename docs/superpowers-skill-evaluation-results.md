## Решение по семи направлениям

Ни один кандидат не прошёл заранее заданные критерии продвижения. Общий прирост числа pass не устраняет регрессию отдельного обязательного критерия; синтетический каталог также не квалифицирует реальную установку. Существующие инструкции сохранены без новых блоков, а все измеренные варианты доступны в fixtures для последующих исследований.
